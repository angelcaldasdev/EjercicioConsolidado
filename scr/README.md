# Ejercicio Consolidado - Java

Ejercicio práctico desarrollado para reforzar los fundamentos de Java,
especialmente el uso de estructuras condicionales.

## 📌 Descripción del programa

Programa de consola que solicita los datos de un estudiante,
valida su edad y su nota, clasifica su rendimiento académico
y determina si aprobó o no.

## 🧠 Conceptos practicados

- `Scanner`
- `if`
- `else if`
- `else`
- Variables
- Operadores lógicos
- Operadores relacionales
- Condiciones anidadas
- Validación de datos

## ⚙️ Funcionamiento del programa

El programa solicita:

1. Nombre y apellido.
2. Edad.
3. Nota entre 0 y 20.

Luego realiza las siguientes validaciones:

- Verifica que la edad sea válida.
- Verifica que la nota esté entre 0 y 20.
- Clasifica la nota.
- Determina si el estudiante aprobó.

## 📊 Clasificación de notas

| Nota | Clasificación |
|------|---------------|
| 0 - 10 | Desaprobado |
| 11 - 13 | Regular |
| 14 - 17 | Bueno |
| 18 - 20 | Excelente |


## 🛠️ Tecnología utilizada

- Java
- IntelliJ IDEA
